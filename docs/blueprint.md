# **App Name**: VetConnect

## Core Features:

- Auto Doctor Assignment: Automatically connect users with nearby available veterinarians based on the animal type.
- Voice-to-Text Symptom Input: Enable users to input symptoms via voice using the Web Speech API.
- Upload Animal Image: Allow users to upload animal images (with camera support).
- Add Symptoms and Create Report: Enable users to add symptoms and create a disease report.
- Manual Doctor Assignment Override: Provide an option for users to manually override the auto-assigned doctor.
- Missed-Call Request: Allow users without smartphones to register symptoms via missed calls.
- Nearby Veterinarian Locator: Display a map of nearby veterinary hospitals using geolocation and Google Maps.
- Disease Information Search: Enable users to search for information about livestock diseases by animal type.
- Alert System: Provide alerts and notifications for disease outbreaks and spread.
- Record History & Reporting Tool: Store and view past reports in a records dashboard. LLM tool can use these historical reports to predict the rate of spread of future diseases.

## Style Guidelines:

- Use 'Poppins' font for all text elements.
- Place content in center cards with shadows and rounded corners.
- Use responsive layout for mobile-first design.
- Dashboard should have a top navigation bar with links: Home, Report, Dashboard, Hospitals, Info, Contact.
- Use a white professional UI theme with green accent color (#4CAF50).
- Buttons and inputs should be large and touch-friendly.
- Subtle animations for loading states and transitions.
